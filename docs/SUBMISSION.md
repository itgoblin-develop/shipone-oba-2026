## 2분 대본

0:00–0:20 할 일은 많지만 끝낸 일은 적습니다. 오늘 가능한 하나와 완료 근거를 함께 관리합니다.

0:20–0:40 60분이 연속으로 비어 있으면 45분 작업은 후보, 90분 작업은 제외됩니다. AI가 단계와 완료 조건을 제안하고 사용자가 확인합니다.

0:40–1:10 도깨비가 곁에 있습니다. 막히면 다음 한 걸음을 질문하고, 다른 생각은 보관합니다. 음성과 브라우저 알림은 선택입니다.

1:10–1:40 결과물에 ‘사전 신청’ 문구가 빠져 2/3 통과. 수정 후 3/3이 되어야 완료 기록을 남깁니다. 자동 검사와 사용자 확인은 구분합니다.

1:40–2:00 키 입력 없이 바로 체험하는 웹앱입니다. 개인 빌더의 실제 완수와 재사용을 검증하고 로그인·OAuth·동기화·서버 푸시로 확장하겠습니다.

## 시연

재현 가능한 시연은 체험 초기화 → 샘플 시나리오 체험. 실제 AI는 오늘의 하나 골라줘. 출처 라벨이 다릅니다. 연결 버튼은 준비 중 안내이며 연결 성공으로 시연하지 않습니다.
