03 / THE COMPLETION LOOP

“다 했어요” 다음에
확인할 근거가 있습니다.

시작 전 · 완료 조건 합의
✕ “사전 신청” 안내 문구 누락
결과물을 수정하고 다시 검사
✓ 자동 검사 + 사용자 확인 완료

근거가 담긴 완료 기록

  • 확인한 조건과 통과 여부
  • 자동 검사와 사용자 확인 구분
  • 검사 시점과 결과물 SHA-256
  • Markdown으로 내보내기

문구·분량 검사는 기능의 정상 동작이나 결과물의 품질 전체를 보증하지 않습니다.
